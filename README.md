# Makhaan Mithila — Official Business Website

Official corporate website for **Makhaan Maa Mahakali India Private Limited** (Brand: **Makhaan Mithila**), premier Makhana manufacturer, processor, and bulk wholesale supplier based in Madhubani, Bihar.

- **Brand:** Makhaan Mithila
- **Legal Entity:** Makhaan Maa Mahakali India Private Limited
- **ESTD:** 2019
- **GSTIN:** `10AASCM7783K1ZU`
- **Location:** Madhubani, Bihar – 847211 / 847212

---

## 🚀 Tech Stack

- **Framework:** React + Vite
- **Routing:** React Router v6 (Multi-page routing: `/`, `/about`, `/products`, `/quality`, `/gallery`, `/contact`)
- **Styling:** Tailwind CSS + Lucide Icons
- **Deployment:** Vercel / Netlify ready

---

## 🛠️ Local Development & Build Commands

```bash
# Install dependencies
npm install

# Run development server
npm run dev

# Build for production
npm run build

# Preview production build
npm run preview
```
